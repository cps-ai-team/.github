## How to contribute

1. **Check the scope first.** Read the *"What belongs here"* and *"What does not belong here"* sections above, and consult `CONTENT-GUIDE.md` if you are unsure.
2. **Open a pull request.** Make your changes on a branch and raise a PR against `main`. Describe what you are adding or changing and why.
3. **Request a review from the owner.** Tag the owner listed in the table above as a reviewer.
4. **Keep changes focused.** One topic or document per PR where practical; this makes reviews faster and the history clearer.
5. **Update the review date** in the owner table when you make a substantive change to an existing document.

For questions about content scope or library ownership, post in [team channel / contact details].
